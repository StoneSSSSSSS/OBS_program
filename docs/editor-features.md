# Editor features

Open **Editor → Workbench** to assemble footage. Open **Editor → Wiki** for searchable instructions that work offline.

| Priority | Task | Available controls |
| --- | --- | --- |
| 1 | Start and return to an edit | Create, open, save and Save As an editable `.cvproj`. Source files stay separate and can be relinked when moved. |
| 2 | Bring in footage and sound | Import or drop multiple videos, still images and audio files. The Media Bin shows file type and duration. Reuse one file at different places in the same cut. |
| 3 | Build the picture sequence | Add and reorder shots, drag their trim handles, set exact Source In and Source Out times, split at the playhead, duplicate and remove. Removing a shot closes its gap. |
| 4 | Check a cut | Play or pause the composed edit, scrub, step one project frame in either direction and enlarge the preview. Use the timeline item picker for an item too short to click. |
| 5 | Mix the soundtrack | Layer voice, music and effects over the video's original audio. Place, trim and adjust each occurrence independently. Fade in or out measured in seconds. |
| 6 | Deliver a watchable file | Select a landscape, portrait or square canvas and 24, 25, 30 or 60 fps. Export a native H.264 MP4 with AAC audio. Progress and Cancel remain available during an export. Open the output folder when it finishes. |
| 7 | Revise safely | Undo and redo picture or audio edits, save a named revision and reopen it. Saving a project keeps edit decisions separate from source media. |
| 8 | Work on a long timeline | Zoom around the playhead, pan, fit the full sequence and navigate directly by time or item. |
| 9 | Add readable text | Insert and edit title and color cards. Add timed captions, import or export SubRip subtitles, and burn the timed captions into the finished video. |
| 10 | Correct orientation | Rotate videos or stills by quarter turns and mirror the result horizontally. Preview the orientation before exporting. |

The editing challenges cover different outcomes, from removing one numbered frame to handing a portable revision to a second editor. [Independent editing challenges](editor-challenges.md)
